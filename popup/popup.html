AUTO-DOCUMENT

Инструмент для извлечения и отправки данных в AutoDealer

Версия 1.0 • Расширение для Chrome и Firefox

Обучение использованию

Расширение извлекает товары с корзины Rossko и отправлять их в AutoDealer для создания калькуляции.

  1. Добавить – добавить все товары с сайта Rossko в список
  2. Редактировать – изменить список товаров, которые попадут в документ
  3. Отправить – наименовать документ и отправить данные на сервер

⚠️ Перед использованием убедитесь, что вы находитесь на нужной странице сайта. Иначе расширение не работает!!!
